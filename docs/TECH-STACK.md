# تکنولوژی‌ها

سایت منتشرشده هیچ وابستگی runtime، CDN یا درخواست شخص ثالث ندارد.

| لایه | انتخاب | دلیل |
|---|---|---|
| ساختار | HTML5 | سه ورودی ایستا |
| ظاهر | CSS با custom property و container query | پیش‌نمایش موبایل به عرض قاب وابسته است، نه مرورگر |
| منطق | JavaScript با ES Modules | تفکیک لایه‌ها بدون build |
| فونت | Vazirmatn، میزبانی داخلی | مستقل از CDN، با مجوز OFL 1.1 |
| تست واحد | `node:test` | داخل خود Node |
| تست مرورگر | Playwright با Chromium، WebKit و Firefox | رفتار، واکنش‌گرایی و CSP در مرورگر واقعی |
| دسترس‌پذیری | axe-core | بررسی خودکار WCAG |
| CI/CD | GitHub Actions | اول تست، بعد انتشار |
| میزبانی | GitHub Pages | ایستا و HTTPS |

## انتخاب‌نشده‌ها

| گزینه | دلیل | کی بازنگری شود |
|---|---|---|
| React یا Vue | پیچیدگی بیشتر از نیاز | وقتی اجزا با محصول مشترک شوند |
| TypeScript | مرحله‌ی build می‌خواهد | وقتی چند توسعه‌دهنده روی domain کار کنند |
| Vite | تعداد و حجم فایل‌ها کم است | وقتی وابستگی runtime اضافه شود |
| Tailwind | CSS موجود کوچک و منسجم است | هنگام اتصال به دیزاین سیستم |

## نیازمندی‌ها

- توسعه: Node 22 یا بالاتر
- مرورگر: Chrome و Edge از 105، Safari از 16، Firefox از 112
- نسخه‌های بالا از روی قابلیت‌های استفاده‌شده‌اند. CI فقط نسخه‌ی فعلی سه موتور را تست می‌کند.
