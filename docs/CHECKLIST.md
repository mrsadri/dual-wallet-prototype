# چک‌لیست انتشار

هر مورد فقط بعد از راستی‌آزمایی تیک می‌خورد.

## حریم خصوصی
- [ ] بدون برند، نام شخص، تماس، تاریخ و آمار واقعی
- [ ] بدون سند داخلی در ریپو و تاریخچه‌ی آن
- [ ] ایمیل noreply در commit
- [ ] `noindex` در همه‌ی صفحه‌ها

## امنیت
- [ ] state از URL اعتبارسنجی می‌شود
- [ ] CSP بدون `unsafe-inline`
- [ ] بدون درخواست شخص ثالث
- [ ] Actions با SHA پین شده و کمترین دسترسی را دارند

## رفتار
- [ ] خروجی با نسخه‌ی اولیه برابر است، جز تغییرهای عمدی
- [ ] همه‌ی سناریوها بدون خطا باز می‌شوند
- [ ] لینک هر سناریو همان حالت را می‌سازد
- [ ] مرزهای برداشت، شارژ و کف منفی تست دارند

## نمایش و دسترس‌پذیری
- [ ] عرض‌های 360، 390، 768، 1280 و 1440
- [ ] کنترل‌ها با کیبورد کار می‌کنند
- [ ] تست مرورگر در Chromium، WebKit و Firefox
- [ ] axe بدون خطای critical و serious

## انتشار

- [ ] سه صفحه و فونت روی لینک عمومی با HTTPS
- [ ] تست مرورگر روی لینک عمومی سبز

## بررسی دستی باقی‌مانده

- [ ] تست با VoiceOver یا TalkBack
