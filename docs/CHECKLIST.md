# چک‌لیست انتشار

## حریم خصوصی
- [x] بدون برند، نام شخص، تماس، تاریخ و آمار واقعی
- [x] بدون سند داخلی در ریپو و تاریخچه‌ی آن
- [x] ایمیل noreply در commit
- [x] `noindex` در همه‌ی صفحه‌ها

## امنیت
- [x] state از URL اعتبارسنجی می‌شود
- [x] CSP بدون `unsafe-inline`
- [x] بدون درخواست شخص ثالث
- [x] Actions با SHA پین شده و کمترین دسترسی را دارند

## رفتار
- [x] خروجی با نسخه‌ی اولیه برابر است، جز تغییرهای عمدی
- [x] همه‌ی سناریوها بدون خطا باز می‌شوند
- [x] لینک هر سناریو همان حالت را می‌سازد
- [x] مرزهای برداشت، شارژ و کف منفی تست دارند

## نمایش و دسترس‌پذیری
- [x] عرض‌های 360، 390، 768، 1280 و 1440
- [x] کنترل‌ها با کیبورد کار می‌کنند

- [x] axe بدون خطای critical و serious
